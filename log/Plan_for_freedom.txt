# Fix Voice Mode MCP Server Freeze — Detailed Plan
# Generated: 2026-02-07

## Context

The `speak` tool in the voice mode MCP server freezes indefinitely. When Claude
calls `speak`, the tool never returns — the user must manually interrupt it.

The root cause is that multiple blocking operations in `speak_text()` and
`speak_text_streaming()` have NO timeout or deadline. If AllTalk stalls
mid-stream, the audio device is contended by another instance, or the drain
loop never exits, the entire tool call hangs forever.

This is a proper fix per DMAIC: we add bounded timeouts to every blocking
operation. No architecture changes. Streaming remains the primary path.
No shortcuts, dummies, or workarounds.

## Change 1: Add Timeout Constants
## Location: after line 37 (after WAV_HEADER_SIZE = 44)
================================================================================

Add these constants to the Configuration section:

    SPEAK_OVERALL_TIMEOUT = 120     # Max total seconds for a single speak() call
    STREAM_DRAIN_TIMEOUT = 15       # Max seconds to wait for audio buffer to drain
    STREAM_ITER_TIMEOUT = 60        # Max elapsed seconds in iter_content loop
    PLAYBACK_DRAIN_TIMEOUT = 30     # Max seconds for _wait_for_playback_or_pause

Rationale for values:
- 120s overall: A long TTS response (~2000 chars) at normal speech takes 60-90s.
  120s gives headroom.
- 15s drain: After all data is written, sounddevice buffers hold 1-3s of audio.
  15s is generous.
- 60s iter: The HTTP streaming loop should complete within 60s. Catches AllTalk
  stalling mid-stream.
- 30s playback drain: For non-streaming paths (Methods 2 & 3), the full audio
  is buffered then played. 30s covers any single utterance.

REPLACEMENT CODE:

    def _wait_for_playback_or_pause(deadline: float = None):
        """Wait for audio playback to complete, with a deadline.

        Args:
            deadline: Absolute time.monotonic() value to stop waiting.
                      If None, uses PLAYBACK_DRAIN_TIMEOUT from now.
        """
        if deadline is None:
            deadline = time.monotonic() + PLAYBACK_DRAIN_TIMEOUT
        while True:
            if time.monotonic() >= deadline:
                sd.stop()
                logger.warning(
                    f"Playback drain timed out after "
                    f"{PLAYBACK_DRAIN_TIMEOUT}s, forcing stop"
                )
                break
            try:
                stream = sd.get_stream()
                if not stream.active:
                    break
            except RuntimeError:
                break
            if is_tts_paused():
                sd.stop()
                logger.info("Playback stopped: TTS paused")
                break
            time.sleep(0.1)

WHAT CHANGED:
- Added deadline parameter (defaults to PLAYBACK_DRAIN_TIMEOUT from now)
- Checks time.monotonic() >= deadline at top of every loop iteration
- Calls sd.stop() and breaks if deadline exceeded
- Uses time.monotonic() (immune to system clock adjustments)
- This automatically fixes Methods 2 and 3 (play_audio_bytes, play_audio_from_url)
  which call this function at lines 190 and 216

    def speak_text_streaming(text: str, voice: str) -> dict:
        """Stream audio from AllTalk's streaming endpoint for low-latency playback."""
        global _streaming_available

        t_start = time.monotonic()
        overall_deadline = t_start + SPEAK_OVERALL_TIMEOUT

        params = {
            "text": text,
            "voice": voice,
            "language": "en",
            "output_file": "streaming_output.wav",
        }

        logger.info(f"Streaming TTS request: text_len={len(text)}, voice={voice}")

        response = requests.get(
            f"{ALLTALK_URL}/api/tts-generate-streaming",
            params=params,
            stream=True,
            timeout=30,
        )
        response.raise_for_status()

        t_after_connect = time.monotonic()
        logger.info(
            f"Streaming TTS connected in {t_after_connect - t_start:.2f}s"
        )

        # Read WAV header from first bytes of stream
        header = b""
        for chunk in response.iter_content(chunk_size=WAV_HEADER_SIZE):
            header += chunk
            if len(header) >= WAV_HEADER_SIZE:
                break

        fmt = _parse_wav_header(header[:WAV_HEADER_SIZE])
        if fmt is None:
            response.close()
            raise ValueError("Invalid WAV header from streaming endpoint")

        sr = fmt["sample_rate"]
        ch = fmt["channels"]
        dtype = "int16" if fmt["bits_per_sample"] == 16 else "int32"
        frame_size = fmt["block_align"]

        logger.info(
            f"Streaming TTS: {sr}Hz, {ch}ch, {fmt['bits_per_sample']}bit"
        )

        stream = sd.RawOutputStream(
            samplerate=sr, channels=ch, dtype=dtype
        )
        stream.start()

        leftover = header[WAV_HEADER_SIZE:]
        remainder = b""
        bytes_written = 0
        chunks_received = 0
        iter_start = time.monotonic()

        try:
            if leftover:
                remainder = leftover

            for chunk in response.iter_content(chunk_size=STREAMING_CHUNK_SIZE):
                now = time.monotonic()
                chunks_received += 1

                # Check overall deadline
                if now >= overall_deadline:
                    logger.warning(
                        f"Streaming TTS hit overall timeout "
                        f"({SPEAK_OVERALL_TIMEOUT}s) after "
                        f"{chunks_received} chunks, {bytes_written} bytes"
                    )
                    break

                # Check iter-loop deadline
                if now - iter_start >= STREAM_ITER_TIMEOUT:
                    logger.warning(
                        f"Streaming iter_content loop timed out "
                        f"({STREAM_ITER_TIMEOUT}s) after "
                        f"{chunks_received} chunks"
                    )
                    break

                if is_tts_paused():
                    logger.info("Streaming playback stopped: TTS paused")
                    break

                data = remainder + chunk
                usable = len(data) - (len(data) % frame_size)
                if usable > 0:
                    try:
                        stream.write(data[:usable])
                        bytes_written += usable
                    except sd.PortAudioError as e:
                        logger.error(
                            f"stream.write() failed: {e} "
                            f"(after {bytes_written} bytes written)"
                        )
                        break
                remainder = data[usable:]

            # Write any final remainder
            if remainder and not is_tts_paused():
                pad = frame_size - (len(remainder) % frame_size)
                if pad < frame_size:
                    remainder += b"\x00" * pad
                try:
                    stream.write(remainder)
                    bytes_written += len(remainder)
                except sd.PortAudioError as e:
                    logger.error(f"Final stream.write() failed: {e}")

        finally:
            # Drain with deadline
            drain_deadline = min(
                time.monotonic() + STREAM_DRAIN_TIMEOUT,
                overall_deadline,
            )
            drain_start = time.monotonic()
            while stream.active:
                if time.monotonic() >= drain_deadline:
                    logger.warning(
                        f"Stream drain timed out after "
                        f"{time.monotonic() - drain_start:.2f}s, forcing stop"
                    )
                    break
                if is_tts_paused():
                    logger.info("Draining stopped: TTS paused")
                    break
                time.sleep(0.05)

            stream.stop()
            stream.close()
            response.close()

            t_end = time.monotonic()
            logger.info(
                f"Streaming TTS complete: {bytes_written} bytes, "
                f"{chunks_received} chunks, "
                f"total={t_end - t_start:.2f}s "
                f"(connect={t_after_connect - t_start:.2f}s, "
                f"stream={t_end - t_after_connect:.2f}s)"
            )

        _streaming_available = True
        return {"status": "spoken", "voice": voice, "length": len(text)}

WHAT CHANGED:
- overall_deadline computed at function entry from SPEAK_OVERALL_TIMEOUT
- iter_content loop checks both overall_deadline and STREAM_ITER_TIMEOUT
- stream.write() wrapped in try/except sd.PortAudioError (catches locked device)
- Drain loop uses min(STREAM_DRAIN_TIMEOUT, remaining overall time) as deadline
- Phase timing logged: connect time, stream time, total time, bytes/chunks

WHY +5 SECONDS:
The +5 buffer lets internal deadlines (SPEAK_OVERALL_TIMEOUT=120s) fire first
and do clean cleanup. The async timeout (125s) is the fallback safety net.
Internal deadline fires → cleans up streams/responses → returns normally.
Async timeout only fires if internal cleanup itself hangs.
